진행 단계

현재:

결과 발표를 누르면 신청자 전원에게 학교 메일이 발송돼요.

발표하면 단계를 되돌릴 수 없어요. 답변 기한은 발표 시점부터 48시간이에요.

따로 안 눌러도 답변 마감 24시간 전에 자동으로 한 번 보내요.

③ 매칭

신청을 마감한 뒤 미리보기로 확인하고 확정하세요. 확정은 다시 눌러도 덮어써져요(발표 전까지).

신청 현황

신청자 · 제재

신고 많은 순. 제재하면 매칭에서 빠지고, 이미 매칭된 상대에게는 "매칭 취소"로 보여요.

🛡 보안 · IP 차단

최근 24시간 동안 요청 제한 초과, 인증 코드 틀림, 관리자 로그인 실패가 많았던 IP 순이에요. 차단하면 그 IP는 사이트 API를 전혀 못 써요(10초 안에 적용).
